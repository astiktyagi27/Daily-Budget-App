# Feature Index

Every feature has **three files with the same name** in three folders:

| Folder | File | Written by | Answers |
|---|---|---|---|
| `docs/features/` | `F-xxx-name.md` | Product Manager (+ Developer at the end) | **What** is this feature and how should it behave? |
| `plans/` | `F-xxx-name.md` | Developer, approved by Project Manager | **How** will we build it? |
| `tests/` | `F-xxx-name.md` | Tester, approved by Project Manager | **How** do we prove it works, including edge cases? |
