**D-025 (NDK pinned to 30.0.16248370 instead of `flutter.ndkVersion` 28.2.13676358): confirmed.**
- **Why it is needed:** Flutter 3.47.9 hard-codes 28.2.13676358 (`FlutterExtension.kt`), and Gradle could not download it automatically through the cmdline-tools 23.0 sdkmanager. That is a tooling gap, not a project choice.
- **Why NDK 30 is acceptable:** it is newer, and pinning a newer NDK than Flutter's default is the normal fix Flutter itself suggests when plugins need one. It is also consistent with STANDARDS §2 (latest stable).
- **Cost:** the version is now a literal, so every machine must have NDK 30.0.16248370 installed. That is acceptable for a one-developer-machine project if it is written down.
- **Conditions (recorded in D-025):**
  1. README §13 names the NDK version (N5 below).
  2. The Phase 2 plan re-verifies that `sqlite3`/`drift_flutter`'s native build hooks compile with NDK 30.
  3. Switch back to `flutter.ndkVersion` once Flutter's default is 30 or higher.
- **Not chosen:** installing 28.2 instead. It would also work, but it is an extra ~1 GB download for an older NDK with no benefit.
