## 0. How to run these cases

**Environment and shared definitions:** as F-010 §0 (data sets **A13**, **A13c300**, **S8**, **M20** (the canonical shared seed, `phase3_fixtures` `m20`), **F12**, the harness list and the harness additions), which uses F-002 §0 (**T5**, **Small**, **X1/X2**, **Overflow check**), F-007 §0 (**[MEM]**, **[EMU]**, **[FAKE]**), F-008 §0 (**Today(d)**, **Fake repos**, **Sheets and finders**, `findCopy`) and F-009 §0 (editor drivers `pumpTransactions`, `tapLabel`, `typeInto`). The real F-006 engine is used for every figure; covers in widget tests go through `FakeSavingsRepository.cover`, which calls the engine's `checkCover` exactly like the real repository. The sheets are decision sheets found by text (never `AlertDialog`).
