## 0. How to run these cases
Environment, **T5**, **Small**, **X1/X2**, **P1 screens**, **FakeStore**, **Restart (sim/real)**, **Fresh (real)**, **No-error UI**, **Overflow check** and **[P]** are defined in [F-002 §0](F-002-design-system-themes.md#0-how-to-run-these-cases-shared-by-f-002--f-005). **Back**, **Route count** and the `SystemNavigator.pop` mock are in [F-003 §0](F-003-app-shell-navigation.md#0-how-to-run-these-cases).
- **Screen identity** (which screen is showing) = its title: slides `Spend a little each day`, `Your daily budget, worked out`, `Saved days add up`, `Private by design`; `Read your bank SMS`; `Get gentle nudges`; `Before you start`; Home = bottom navigation present with Home selected.
- **Flags** = "tour seen" and "onboarding finished" keys the plan names, read from the FakeStore backing map.
- **Swipe left / right** = `tester.drag(find.byType(PageView), const Offset(-300, 0))` / `(300, 0)`, then settle.
- Proposed test files: `test/features/onboarding/welcome_tour_test.dart`, `test/features/onboarding/explainers_test.dart`, `test/features/onboarding/onboarding_routing_test.dart`, `test/architecture/no_permission_request_test.dart`, `integration_test/onboarding_flow_test.dart` (STANDARDS §6: onboarding is a main flow with an integration test).
