## 0. How to run these cases

**Environment and shared definitions:** as F-013 §0 (Phase 3 fixtures **A, F, S** with exact paise), F-002 §0 (**T5**, **Small**, **X1/X2**, **Overflow check**, **No-error UI**), F-007 §0 (**[MEM]**, **[EMU]**, **[FAKE]**), F-008 §0 (**Today(d)**, **Fake repos**, **Sheets and finders**, `findCopy`) and F-009 §0 (**M-E2**, **Today line**, `transactions_harness.dart`). **No new money rule:** the economics are F-006 AC-25 (money in) and F-007 AC-19 (`direction`, D-051); this file tests the **entry UI** and checks that the effects reach the figures. **Scheduling (D-033):** the editor widget tests may run once F-009's editor exists; the effect cases that read Home, the calendar and day details wait for F-010, F-011 and F-012 and are written with an engine half that does not (marked **Pure half**). F-016's switch and F-015 §2.4a's Category row change the same editor (phase overview open item 5); `transactions-search.md` §9 is the single layout.

**Copy and numbers.** Expected strings are literals of F-016 §5 / `transactions-search.md` §9, §15. Money text goes through `findCopy` (U+00A0 and U+2060 ignored). Paise literals below are exact.
