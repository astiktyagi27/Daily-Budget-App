## 0. How to run these cases
Environment, **T5**, **Small**, **X1/X2**, **P1 screens**, **FakeStore**, **Restart (sim/real)**, **Fresh (real)**, **No-error UI**, **Overflow check** and **[P]** are defined in [F-002 §0](F-002-design-system-themes.md#0-how-to-run-these-cases-shared-by-f-002--f-005). Unless a case says otherwise, every case here starts with FakeStore `seeded` = onboarding finished, tour seen and **all four hints dismissed** (so hints don't get in the way; F-004 tests the hints).
- **Back** in a widget test = `await tester.binding.handlePopRoute()`. "App leaves to background" = a mock handler on `SystemChannels.platform` records a `SystemNavigator.pop` call.
- **Route count** = a `NavigatorObserver` in the test counting `didPush`/`didPop`.
- Proposed test files: `test/features/shell/app_shell_test.dart`, `test/features/settings/settings_tab_test.dart`.
